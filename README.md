# Luv Visualz · web integral

Este repositorio publica la web estática de GitHub Pages. La versión recibida
contenía HTML, CSS y JavaScript compilados, sin el proyecto fuente original.
La actualización integral 2.0 evoluciona esos archivos y conserva las rutas
públicas de `work/`.

El contenido del portfolio, los textos en español e inglés y los reproductores
están en `assets/portfolio-C92OWmAS.js`. Los ajustes de estilo están en
`assets/integral-2.css`. Al editar el componente, ejecutar `npm ci` y
`npm run render` para sincronizar el HTML inicial de ambos idiomas y evitar
errores de hidratación. Los metadatos sociales se mantienen en `index.html` y
`en/index.html`. `assets/luv-fixes.js` conserva el juego del manifiesto.

Los MP4 nuevos proceden del repositorio de edición de Luv Visualz, copiados sin
recompresión a este repositorio para que cada web conserve sus propios archivos.
Las portadas de video nuevas son fotogramas reales de esos MP4. Los archivos
originales de `work/artistic/` y las rutas compartidas siguen disponibles.
